Ustawienia AI
Gra działa bez API. Po dodaniu klucza AI może interpretować polecenia, pisać reakcje dyplomatyczne i przygotowywać analizy strategiczne.
Nie umieszczaj klucza w kodzie ani na GitHubie. W tej wersji klucz nie jest zapisywany do localStorage ani do sejwa, ale przeglądarkowa aplikacja nie zapewnia ochrony sekretu przed własnymi skryptami lub rozszerzeniami. Do wspólnego, publicznego klucza potrzebny byłby backend, którego GitHub Pages samo nie uruchamia.
Silnik lokalny jest gotowy. API jest opcjonalne. Domyślny model: darmowy router openrouter/free.
Licznik tokenów działa lokalnie; klucz API nie jest zapisywany.
